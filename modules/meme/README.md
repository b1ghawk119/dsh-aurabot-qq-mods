# 表情制作 · AuraBot 模块

在 QQ 中直接发 **#贴贴 @某人**、**#贴贴**、**#鲁迅说 今天也要开心**。
**@某人时请从 QQ 的成员列表中选择对方**，手打或粘贴 `@昵称` 会作为普通文字使用。
也支持 `#摸摸`、`#表情 摸摸`、附图或引用图片。无需 API Key，也不用单独安装 Python、Docker 或启动其它服务。

默认安装 **732 个模板**（内置库 299 个 + meme-emoji 431 个 + 自带模板 2 个），首次自动准备完成后即可使用。面板中点击 **安装扩展库**，可再增加 **273 个模板**，合计 **1005 个**。按模板标识排重，原库优先。

完整目录图默认 **5 列**；在面板的“目录列数”下拉框中可选 **4 / 5 / 6 / 7 列**，不分页。

## 夜里不让某个群制作表情

打开模块面板的「指定群：表情休息时段」，启用后填写群号，以及开始、恢复时间，再点「保存休息设置」。例如 `00:00` 到 `07:00`，每天凌晨静默，早上自动恢复；也支持 `23:00` 到 `07:00` 这样的跨午夜时段。

默认关闭，只影响填写的群。休息期间不回复该群的表情制作、列表、预览和管理指令；私聊和其他群照常。已开始的制作若到休息时间才完成，不会再发到该群。设置按运行机器的本地时间执行，机器重启后仍有效。

它与 Aurabot 的聊天静默时段独立，不会更改群白名单或 AI 聊天模式。

## 黄仁勋模板

这两个模板属于基础库，不需要安装扩展：

```text
#黄仁勋说 显存不够？再加一张。
#老黄举牌 买得越多，省得越多。
#老黄哭举牌 我的显存呢？
```

“黄仁勋说”也可用 `#老黄说`。“黄仁勋举牌”也可用 `#老黄举牌`，默认笑脸；哭脸可用 `#黄仁勋哭举牌`、`#老黄哭举牌`，或在普通举牌指令末尾加 `--表情 哭`。省略文字时使用默认文案；文字会在指定区域内自动换行、缩放。

## 可选扩展库

在“表情库”中，目录列数右侧可以安装或卸载扩展库：

- **安装扩展库**：已有资源时直接启用；首次使用自动下载资源和所需运行环境，不用手动配置。
- **卸载扩展库**：停止扩展生成进程，把扩展模板移出搜索、列表、目录图和随机选择；**不删除磁盘资源**。
- 再安装会复用保留的资源，收藏、别名和模板开关也会保留。安装过程中基础库继续可用。

首次安装需要联网，安装后离线生成。旧版本已启用的扩展在升级后继续启用。

## 安装后自动准备

在模块市场安装“表情制作”，打开“表情库”等待准备完成即可。手动安装时，把完整模块目录放到 `~/.dsh/plugins-data/aurabot/modules/meme/`。**无需运行安装命令、npm install，也不用配置 API Key 或 Python。**

首次启动会自动识别系统，下载运行组件和基础素材。面板显示当前阶段与进度；完成后直接发送 `#摸摸`、`#黄仁勋说 你好` 使用。网络失败时点击 **重试准备**，不用重新配置。默认只准备 732 个基础模板，不下载 Python 扩展。

- 每个素材库下载一个固定版本的归档，流式解压；不逐文件请求 GitHub，不使用 GitHub API 补图，也不要求安装 Git。不保留压缩包副本或 `.git` 历史。
- 完整素材库直接复用；库不完整时按整包重新获取，只提取需要的源码/素材目录。运行组件按已提交的 npm 完整性值校验后安装。独立平台组件使用固定发行文件和完整性值，必要时请求 GitHub 发行文件 API，不按模板或图片调用 API。
- 新的轻量安装把组件与素材放在模块数据目录的 `runtime/` 下，更新模块代码时可以复用。原有完整安装继续使用原路径，不搬动或重装已可用的库。
- 首次准备需要联网和足够的磁盘空间，基础资源约 943 MiB；完成后离线生成。可选扩展另由面板安装按钮管理。

**完整离线包**：复制已准备好的整个 `meme` 目录（包含隐藏的 `node_modules`），会直接加载，不重复下载。

开发者也可保留原来的命令行安装方式：`node scripts/install.mjs [目标目录]`。加 `--with-extension` 可同时预装扩展；安装器不会覆盖已有模块。

### 支持的系统

安装时不需要选系统。Windows x64、Linux x64/ARM64、macOS Intel/Apple Silicon 使用同一个模块包；运行组件会自动匹配，模板素材共用。Docker 内按 Linux 处理。

Windows x64 已实测；Linux x64 容器及 ARM64 仿真容器已验证；macOS 已适配，尚未实测。Linux / Docker 推荐 Debian 12 或 Ubuntu 22.04 及以上，不支持 Alpine，部署要求见 [安装说明](docs/DOCKER.md)。

从 1.3.6 起，安装前会检查支持的系统、下载工具及 Linux 所需组件；缺少时，面板显示简短提示和“安装说明”。补齐后点击 **重试准备** 或 **安装扩展库**，已有资源继续复用。扩展缺少组件不影响基础库。

若提示“下载工具不完整”：请让部署者检查运行 DSH 的环境是否能执行 `curl --version` 和 `tar --version`。Linux / Docker 按上述安装说明补齐；Windows 请使用带有 curl、tar 的正常系统环境，并确认 DSH 能访问它们。Windows 原生引擎还需要 VC++ 运行库；这项未纳入本次自动检查。

### 模块市场

模块已通过 [官方仓库 PR #185](https://github.com/aureth-labs/dsh-aurabot-qq-mods/pull/185) 合并审核；市场可安装版本以官方发布目录为准。轻量安装包约 1 MiB，已通过真实市场安装器和 Windows 生产空白安装验证自动准备与扩展管理。

市场安装包使用 `npm ci && npm run build` 构建到 `.build/`，不包含约 943 MiB 的基础资源。使用者只需在市场安装模块并等待准备完成，无需执行命令。Windows 本次从空白安装实测：基础库约 88 秒，可选扩展约 157 秒；缓存再次启用不到 1 秒。首次准备时间取决于网络。

源码已公开。首次准备会下载固定版本运行组件，分发方式已在 PR 中说明并获审核通过；图片素材的许可与代码许可分别列明。[下载来源、版本校验与许可清单](docs/SUPPLY_CHAIN.md)。

## 指令

| 指令 | 用法 |
|---|---|
| `#表情帮助` | 指令清单 |
| `#表情列表图片` | 全部模板的单张目录图：编号、中文触发词、图片/文字参数图标；不分页 |
| `#表情列表 2` | 全部模板的第 2 页 |
| `#表情搜索 举牌` / `#表情搜索 举牌 2` | 搜索模板；末尾加页码翻页，结果附带上一页/下一页指令 |
| `#表情详情 贴贴` | 触发词、图片/文字数量、参数 |
| `#表情预览 贴贴` | 查看示例 |
| `#贴贴 @某人` | 使用双方头像 |
| `#贴贴` | 使用发送者与机器人头像 |
| `#鲁迅说 今天也要开心` | 带文字制作；不填文字使用模板默认文本 |
| `#表情 模板 文字1 / 文字2` | 多段文字 |
| `#摸摸 --circle true` | 类型化参数，兼容 `#circle true` |
| `#表情 随机` | 随机选择一个模板 |
| `#表情排行` / `#表情状态` | 使用次数与制作状态 |
| `#表情禁用 名称` / `#表情启用 名称` | 主人管理单个模板 |
| `#表情别名 新词=模板名` | 主人添加触发词 |
| `#表情开` / `#表情关` | 主人切换制作功能 |

主人还可使用 `/表情`、`/meme`。面板提供模板搜索、预览、收藏、开关、自定义触发词添加/移除；修改立即生效。目录列数变化会在下次请求目录图时使用。

### 输入补齐规则

- 取图顺序：本条附图 → 引用消息中的图片 → 显式 @ 的头像。引用图片时，QQ 自动附带的作者 @ 不作为头像参数。双头像模板只有一个目标时，把发送者放在第一位。
- 没有 @ 或图片时，先用发送者头像，再用机器人头像补足模板最少数量。更多图片位继续复用机器人头像。
- @机器人作为唯一目标时保留它的头像；同时有实际目标或附图时，开头的 @机器人作为呼叫不占图片位。
- 文字不足或多段文字中有空段时，按模板默认文字补齐，没有默认文字则用发送者昵称（再兜底“你好”）。不需要文字的模板不会误用预览文案。
- 单段文字中的 `/`、换行和空格会保留。多段文字用 `/` 分隔，某一段需要包含 `/` 时用引号包住，例如 `"甲/乙" / 第二段`。需要原样输入以 `#` 或 `--` 开头的文字时，在文案前加 `-- `。
- 所有制作、查询和管理指令默认必须以 `#` 开头，普通聊天不触发。可在面板打开“允许省略 #”；触发词后仍需空格或消息结束。主人原有 `/表情`、`/meme` 命令保留。

### 离线与隐私

模板资源、字体、合成均在本机；不会上传输入到第三方表情 API。QQ 消息投递、首次获取 QQ 头像/远程图片仍需 QQ 网络，头像短期缓存于内存。已经提供图片字节或纯文字时，引擎不需要联网。首次自动准备访问 github.com、api.github.com、codeload.github.com、release-assets.githubusercontent.com、registry.npmjs.org；安装可选扩展还需访问 pypi.org、files.pythonhosted.org。QQ 头像来自 q1.qlogo.cn，消息图片按 OneBot 返回的地址获取。普通生成请求不下载代码、素材或字体。

### 性能与维护

独立子进程执行渲染，不阻塞 DSH；新增模板需要的运行进程仅在首次使用时启动，无 HTTP 服务或端口；串行生成、最多 6 个任务、45 秒超时后回收重建。每人默认冷却 3 秒；输入每图 8 MiB、1600 万像素、300 帧上限；输出 20 MiB 上限。目录图按需生成并在内存中复用，禁用列表或列数变化后重新生成。不预生成全部预览、不持久缓存成品。安装/卸载扩展后目录缓存自动更新，不运行自动在线更新任务。

自动准备的依赖放在 `modules-data/meme/runtime/node_modules/`，其中基础资源、可选扩展分别位于 `.meme-runtime`、`.meme-python`。原有完整安装仍使用模块目录里的 `node_modules`；这些资源不进入热重载快照。配置由 AuraBot 保存；统计在 `modules-data/meme/statistics.json`。禁用模块会终止其生成进程树，不影响其它模块。基础准备仅由模块启动/重试发起，扩展准备仅由面板安装操作或安装脚本发起，不由聊天触发下载。异常诊断只记入本机日志，聊天和面板只显示适合用户的提示。

用 `node scripts/pack.mjs /path/to/meme /path/to/meme-offline.tar.gz` 打包基础库；加 `--with-extension` 才会包含可选扩展资源与运行环境。打包器会自动寻找相邻的持久资源目录，也可用 `--runtime-dir 目录` 指定；不复制第二套大素材库。原生依赖按操作系统分发。
